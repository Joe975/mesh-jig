Reference sheets and the models built from them

Each sheet was given to an AI model, which wrote a Blender script to build it in 3D with mesh-jig, tools that measure each build against the sheet. Each company's best and the overall worst are picked by eye from completed builds. Time and cost are for the whole run; subscription tools don't report a cost. Drag a model to turn it.
