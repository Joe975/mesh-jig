Reference sheets and the models built from them

Each sheet was given to an AI model, which wrote a Blender script to build it in 3D with mesh-jig, tools that measure each build against the sheet. Pick a provider and a model to see its best build of each sheet; a model with a rig shows its rigged build and plays its animations. Drag a model to turn it.

OpenAI: four fresh experiments, 10 November 2026

Five successful evaluated models per worker, selected by that worker’s visual review. All 20 fail the 0.40 resemblance gate. Selected and numeric-best scores are distinct. The chosen rigs pass 24 fps contract checks and 60 Hz sampled numeric bounds, which do not certify convincing movement or foot contact. These are completed experiments, not finished-quality assets. Subscription usage and cost are not reported. Historical Fable harness provenance, workflows and runtime differ; this is not a controlled equal-runtime comparison.
